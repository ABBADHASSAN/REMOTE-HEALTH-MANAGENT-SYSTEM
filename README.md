Follow these steps to run a basic Java project in Visual Studio Code.

1. Install VSCode
Download and install Visual Studio Code.

2. Install Java
Make sure Java is installed. You can check it with:

run in cmd :
java -version
If not installed, download from Oracle or AdoptOpenJDK.

3. Install VSCode Extensions
Open VSCode and install these extensions:

Java Extension Pack (by Microsoft)

4. Open the Project Folder
Open VSCode.

Go to File > Open Folder and select your project folder.

5. Create and Run Java Files
Create your .java files inside the folder (e.g., Main.java).

Right-click on the file and select Run Java.

Make sure your Java file has a public static void main(String[] args) method to run properly.

6. (Optional) Set Java Path in VSCode
If VSCode doesn't detect Java automatically:

Press Ctrl + Shift + P, then type settings.json.

Add this line with your Java path:


"java.home": "C:\\Path\\To\\Your\\JDK"
